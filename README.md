# 🏛️ لوحة القيادة المؤسسية — جمعية تراؤف لرعاية الأيتام

لوحة قيادة تفاعلية شاملة لعرض الأداء المؤسسي أمام مجلس الإدارة.

## ✨ المميزات
- 📊 **14 تبويب تفاعلي** تغطي جميع محاور الأداء المؤسسي
- 🌙 **الوضع الداكن** مع حفظ التفضيل
- 📱 **تصميم متجاوب** يعمل على جميع الأجهزة
- 📈 **رسوم بيانية تفاعلية** باستخدام Chart.js
- 🖨️ **دعم الطباعة** المحسّن
- ✨ **تصميم Glassmorphism** مع أنيميشن متقدم
